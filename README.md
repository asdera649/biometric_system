# Интеллектуальная система биометрической аутентификации

ВКР: «Интеллектуальная система авторизации пользователей сайта по лицу с интегрированной защитой от подделок»

## Стек технологий

| Слой | Технология |
|------|-----------|
| Backend | Django 4.2, Python 3.10+ |
| Детекция лица | MTCNN (facenet-pytorch) |
| Эмбеддинги | InceptionResNetV1 предобученная на VGGFace2 (512d) |
| Метрика схожести | Косинусное расстояние |
| Качество кадра | Лапласиан + яркость + контраст (OpenCV) |
| Живость |  |
| Frontend | Bootstrap 5, Chart.js, Web Camera API |
| БД | SQLite (dev) / PostgreSQL (prod) |

## Быстрый старт

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Применить миграции
python manage.py migrate

# 3. Создать администратора
python manage.py shell < create_superuser.py

# 4. (Опционально) Загрузить демо-данные
python manage.py shell < generate_demo_data.py

# 5. Запустить сервер
python manage.py runserver
```

## Архитектура нейросети

### Пайплайн аутентификации:
```
Камера → MTCNN (детекция + выравнивание) → InceptionResNetV1 (512d эмбеддинг)
→ Косинусное сходство с эталоном → Порог → Решение (доступ / отказ)
→ [Liveness Detection]
```

### Метрики качества (Отчёты → `/operator/reports/`):
1. **Уверенность распознавания** — косинусная схожесть с эталонным шаблоном (0–100%)
2. **Качество изображения** — комплексная оценка (резкость, яркость, контраст, разрешение)
3. **Детекция живости** — *(заглушка, место для интеграции LSTM/3D CNN)*
